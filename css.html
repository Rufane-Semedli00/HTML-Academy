03 / CSS STYLING

CSS ilə Mətn dizaynı

Mətnlərin görünüşünü CSS xüsusiyyətləri ilə dəyişdirək.

CSS nədir?

CSS veb səhifələrin görünüşünü formalaşdıran üslub dilidir. Mətnin rəngini, ölçüsünü, şriftini, hizalanmasını və digər xüsusiyyətlərini dəyişməyə imkan verir.

Əsas CSS xüsusiyyətləri

color

Mətnin rəngi

color: purple;

font-size

Mətnin ölçüsü

font-size: 25px;

font-family

Mətnin şrifti

font-family: Georgia;

text-align

Mərkəzləşdirilmiş mətn

text-align: center;

font-weight

Qalın mətn

font-weight: bold;

text-decoration

Altı xətli mətn

text-decoration: underline;

HTML və CSS birlikdə

<h1 class="title">Salam Dünya!</h1>

<style>
.title {
    color: #8b5cf6;
    font-size: 40px;
    text-align: center;
    font-weight: bold;
}
</style>
GÖRÜNÜŞ NÜMUNƏSİ

Salam Dünya!

HTML struktur yaradır, CSS isə görünüş verir.
